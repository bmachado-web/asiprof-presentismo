Cómo obtener las credenciales OAuth2 (una sola vez)
1
Ir a Google Cloud Console
Entrá a console.cloud.google.com y creá un proyecto nuevo (ej: "PresenQR").
2
Habilitar la Google Sheets API
Menú → APIs y servicios → Biblioteca → buscar "Google Sheets API" → Habilitar. Hacer lo mismo con "Google OAuth2 API".
3
Crear credenciales OAuth2
Credenciales → Crear credenciales → ID de cliente OAuth → Tipo: Aplicación web.
En Orígenes autorizados: https://tudominio.com
En URI de redireccionamiento: https://tudominio.com/auth/callback
4
Configurar el archivo .env
Copiá el Client ID y Client Secret que te muestra Google y pegálos en el archivo .env del servidor (ver .env.example incluido en el proyecto).
5
Iniciar sesión
Con el servidor corriendo, hacé click en Conectar Google arriba a la derecha. Se abre el login de Google y listo — las credenciales quedan guardadas en la sesión del servidor.
